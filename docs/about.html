التقنيات المستخدمة

Vanilla JavaScript

بنية معيارية بدون frameworks، سريعة وخفيفة مع Foundation API مركزي.

CSS3 حديث

تصميم متجاوب بالكامل مع Grid و Flexbox، يدعم جميع أحجام الشاشات.

Socket.io

اتصال لحظي لألعاب الشطرنج الأونلاين عبر Node.js server.

AI مدمج

مساعد ذكاء اصطناعي داخل كل لعبة يدعم Gemini API لتقديم النصائح.

Supabase

قاعدة بيانات سحابية للبروفايلات، الإنجازات، ولوحات الصدارة العالمية.

PWA

يمكن تثبيت التطبيق على الهاتف ويدعم اللعب بدون إنترنت للألعاب المحلية.
